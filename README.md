# ZWAM OS 7

Premium personal control center for HAVIT TWS984, INFINIX Watch H4 and music services.

## Includes
- Adaptive AMOLED dashboard
- HAVIT TWS984 center with noise-control UI, latency, battery and diagnostics
- Bass Control Pro with 10-band EQ and custom presets
- Pro audio modes
- INFINIX H4 Watch Center + 240×284 watch-face studio
- Spotify PKCE integration, with DJ LIVI only inside Spotify
- Separate music hubs for Apple Music, YouTube Music, SoundCloud and Deezer
- PWA-ready architecture
- GitHub Pages deployment workflow

## Reality-first integrations
Web browsers cannot universally control proprietary earbud/watch features. ZWAM labels controls as ready, assisted or unavailable instead of faking device state. Spotify playback control requires a Spotify Premium account and a valid Web Playback SDK setup.

## Local development
